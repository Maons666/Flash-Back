# 背闪训练器 · Flash Dodger

Windows 本地桌面训练应用 v0.9。使用独立窗口，完全离线运行，不需要浏览器、网页服务或 VALORANT 客户端。当前按国际服 PC、13.09 公开资料建立基线；不是逐帧认证复刻。

## 启动

从 [v0.9 Release](https://github.com/Maons666/Flash-Back/releases/tag/v0.9) 下载 `Flash-Back-v0.9-win-x64.zip`，完整解压后运行 `FlashDodger/FlashDodger.exe`。从源码启动时，双击根目录的 `Start-Trainer.cmd`，或运行下方的开发命令。便携版已包含运行环境，移动时请保留整个 `FlashDodger` 文件夹。设置和训练记录在程序目录下的 `userdata/` 中。关闭窗口即可退出。

默认使用 **1600 DPI × 0.175**，280 eDPI，理论 46.65 cm/360°、23.33 cm/180°。输入鼠标的实际 DPI；程序不会改变鼠标硬件 DPI。视野为 103°，固定 16:9。点击「操作与校准」可进行不出闪的 180° 距离校准。

## 训练

- 原地背闪：固定站位，练转身及回正。
- 自由移动：WASD 移动，Shift 静步，Ctrl 蹲下，利用掩体切断闪光视线。
- 行进过点：走进地面的绿色圆圈触发来闪，过完四个点回到起点。
- 左键射击可破坏的技能；R 取消未完成轮次并回到起点；Esc 暂停并释放鼠标；F11 切换应用全屏。
- 四种场地，支持点击俯视网格添加/删除箱体。自定义箱体参与移动碰撞和闪光遮挡。
- 可选单一特工与投法，也可随机混合 8 位闪光/电浆特工。最短间隔后附加 0–1.3 秒随机等待，减少按节奏预判。
- 自动保存最近 200 条成绩；支持 CSV 导出。反应时间从技能首次进入视野到明显转向/位移起计，未检测到动作时显示空值。回正从引爆后到回到初始视角 10° 内起计，转身至少 70° 才记录。

## 技能覆盖和精度

闪光/致盲：Hush、Phoenix、Breach、Skye、KAY/O、Yoru（含分身）、Vyse、Gekko。附加近视专项：Reyna、Omen、Fade、Harbor（涡流和水浪）。本应用训练这些技能对单个玩家的影响，不是完整特工操控模拟器，也没有模拟整场对局或技能经济。

公开资料查阅于 **2026-11-02，参考版本 13.09**，不表示每个数值均已实测。Hush 支持空中改向、接触引爆、延时引爆。13.09 公告未提供的 Hush 精确引信与满闪时间默认采用 **1.15 / 1.5 秒的可调训练值**，请勿当作游戏实测值。调整入口位于她的技能卡内。

v0.9 将 Skye 的飞行与激活后 0.3 秒引爆前摇拆开，加入最长飞行后的自动激活；按实际碰撞时刻更新 KAY/O 和 Yoru 引信；Dizzy 可检测露出的身体，已发射电浆不随本体被击毁而消失。首见判定使用与画面一致的 103°、16:9 矩形视锥。闪屏每显示帧更新，鼠标事件前同步模拟时间，移动子步不超过 1/240 秒并在定时事件边界分割；这些是数值积分与呈现修正，不是与 Riot 引擎的误差保证。

每种投法的时序现在标注「官方公告／规则推算／待实测／用户校准」。点击技能卡的「实测校准与来源」，可以逐帧换算、填写实测时序，或导入按角度和距离测得的致盲时长表。数据在本机保存，可以导入、导出、恢复默认；超出采样距离时回退近似，并在 CSV 标注 `outside-samples`。新记录保留版本、模拟修订、采样来源与误差模型。详见 `docs/CALIBRATION.md`。

普通闪光按爆点视线、朝向和距离衰减。Riot 没有公开完整衰减曲线，本程序采用可审查的近似曲线（`src/math.js`）；背身仍保留很短的残闪。有效规避的训练阈值为爆点夹角 ≥100°，或成功用掩体挡闪。这个阈值是训练规则，不是官方判定。

Gekko 的电浆及 Omen、Fade、Harbor 的近视不能靠背身免疫。Reyna 的近视随视线持续生效。击毁技能与躲避技能在记录中区分。近视使用约 7 米视距与边缘遮罩。射击是简化的瞄准命中，不模拟武器散布、后坐力或穿透。

轨迹、世界比例、移动加速、声音与 VFX 为原创近似，尤其 Hush 时序、Skye 飞行、Yoru 分身、Dizzy 锁定和近视追踪都需要后续游戏录像校准。未提取游戏资源，没有接入、注入或修改游戏，也不读取 VALORANT 进程。不能保证与游戏逐帧相同。亮度和音量可调，亮度不影响成绩。

原始输入通过 Chromium 的 `unadjustedMovement` 请求；界面显示请求结果，不声称绕过了所有硬件和系统因素。0.07°/count 灵敏度系数为常用社区测量值。物理一致性应使用尺子与游戏内 180°/360° 实测校准。

完整公开资料与待校准项目见 `docs/MECHANICS.md`，应用内「技能档案」也提供来源链接。点击资料链接时才会使用系统浏览器；训练本身不使用浏览器窗口或网络。

## 开发

需要 Node.js 22+。首次 `npm ci` 下载开发依赖；已打包版无需 Node。

```text
npm start            # 构建并启动桌面程序
npm run package      # 输出 release/FlashDodger/FlashDodger.exe
```

`src/` 为训练与绘制逻辑，`public/` 为界面，`desktop/` 为桌面壳，`scripts/` 为启动/构建/打包。Three.js 与 Electron 依赖固定版本并锁定在 `package-lock.json`。本工具为非官方个人训练项目。

仓库包含程序源码、构建脚本、参数来源与校准说明。测试代码、截图、训练记录、个人校准数据和构建产物不纳入 Git；Windows 便携程序通过 Release 单独提供。
