# v0.10.1 · 卡片布局与第一人称一致性

特工卡改为图片覆盖整个区域，底部四分之一从深色向上渐隐，并叠加特工名称。取消旧图片容器的固定窄宽度和负偏移。场地按钮改为固定图标列，L 型拐角图标的线条在画布中央对齐。

从接收闪光的玩家视角检查了所有投法，并修复以下问题：

- Phoenix 曲闪会先选择完整弧线能够通过、爆点对玩家可见的真实拐角；避免预设路线撞到自身拐角后，在墙后无效爆开。
- Yoru 墙弹检查反弹前后的整段路径，避免默认墙弹实际退化成地弹，或反弹后再次撞墙、飞到视野外。确实没有可用路线时仍显示退回地弹的说明；不会穿墙或强行改变爆点。地弹预设也重新安排了出手位置与角度。
- Yoru 反弹前不播放敌方出手提示音，也不会在激活后补画此前隐形阶段的尾迹。规则依据为 [Riot 11.10 公告](https://playvalorant.com/en-us/news/game-updates/valorant-patch-notes-11-10/)。
- Fade 侧翼预设的出发位置避开墙体，避免黯兽一生成就卡在 L 型墙中。
- Harbor 地面涡流以可见圆环参与首见计时，不再只检查可能位于屏幕下方的圆心。
- 预览和正式训练共同使用闪光、电浆、近视遮罩渲染；修复预览缺少近视遮罩，以及从观察视角切回玩家时残影取景不一致。
- 亮度滑杆现在调整闪屏亮度，不再让满闪阶段因亮度降低而透出实时场景。曝光持续时间与判定不变。

验证包含 43 项机制检查、原有 1,104 组场景运行，以及固定站位、方向和参数下 46 种投法的训练/预览第一人称画面与效果层逐像素比较。卡片与按钮在 1100、1440、1920 像素窗口宽度下检查。

上述一致性指本程序的第一人称训练与预览使用同一套规则和呈现。与真实 VALORANT 的逐帧一致性仍未获得实录标定；已有弹道估计、Hush 时序和声光近似的限制继续适用。掩体遮挡、未射击 Yoru 分身、站在 Harbor 范围外等情况仍按实际机制判定，不强制每次都使玩家受闪。
