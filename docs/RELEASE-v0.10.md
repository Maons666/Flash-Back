# v0.10 · 投法与呈现重做

KAY/O 原来靠近地面出现后弹跳的问题，改为从约 1.6m 出手高度开始、连续计算飞行和实际表面碰撞。Skye 改为按弧长推进的飞行路线；默认参考速度为 18m/s，绕角路线优先选择实际掩体边缘，飞行方向驱动鸟身、翅膀和转弯倾斜。所有路线仍是训练场景，不是职业选手点位库或完整施法者操控模拟。

原地、自由移动、行进过点模式均可选择投法。新增同一特工随机投法。场地扩展到 48×54m 以容纳长抛；编辑器仍编辑中央区域的自定义箱体。没有合适墙面时，KAY/O 弹墙预设会明确提示退回上手抛投；路线遇到新增掩体时按真实碰撞处理，不强行穿墙或拉回预设终点。

## 声光、素材与检查入口

- 替换官方特工立绘和技能图标，随程序提供官方演示。每个文件都有来源记录。
- 重建鸟的分层羽翼、手雷外壳、Hush 灯笼、Dizzy 双眼外形、玫瑰等模型；增加短暂飞行尾迹、充能和激活状态。3D 模型并非原版游戏网格。
- 闪屏使用不同特工的色调、放射光和渐隐；Dizzy 电浆使用不规则遮挡。亮度设置保留。
- HRTF 声音随方向、距离和墙体遮挡变化；KAY/O 飞行阶段不添加持续提示声，末段提示与反弹激活分开处理。部分事件使用官方演示音频短节选；缺失的音效仍是合成重建。
- 「投法预览 / 官方参考」提供时间轴、慢放、接收者/近景/侧面视角、实际已走过的轨迹和碰撞次数。官方视频独立播放；「模拟音效」可单独打开。预览与训练成绩分离。

## 精度与校准

时序依据沿用国际服 PC 13.09 基线，未确认的数据继续标为待实测。速度、重力、反弹损耗现在可按投法保存和导入导出；调速度不会重新移动发射点来掩盖落点变化。具体测量口径见 [CALIBRATION.md](CALIBRATION.md)。

KAY/O / Skye 等初速度参考社区资料；世界单位换算、重力、反弹系数、Skye 操控曲率、Hush 引信、视觉渐隐和部分声音仍待当前游戏实测。本版本不能给出可信的还原百分比，也没有穷尽所有地图上的具体 line-up。

本地验证覆盖 39 项机制检查，其中包含 46 种投法在四种场地、左右两个方向、三个站位共 1,104 组运行；桌面检查覆盖全部 46 种预览、14 段官方视频解码播放、12 段音频解码及校准持久化。此类检查证明实现按自身参数运行，不能替代游戏实录对比。测试代码按要求仅留本地，不进入仓库或安装包。
