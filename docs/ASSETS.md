# 原版素材与重建内容

本版本用于私人本地训练。下载时间：2026-11-03。

| 内容 | 本版本使用方式 | 来源性质 |
| --- | --- | --- |
| 9 张特工立绘 | 特工选择卡片，界面裁切展示 | Riot 官方原图 |
| 10 个技能图标 | 当前技能卡，包括 Yoru 分身 | Riot 官方原图 |
| 10 段技能演示 | 预览窗口右侧，离线播放 | Riot 官方原视频，部分展示旧版本平衡 |
| 11 段短音频 | Hush、KAY/O、Yoru、Vyse、Gekko 的部分事件 | 从上述官方视频剪裁，可能包含环境声；不是独立游戏音效文件 |
| 其余声音 | 翅膀、提示、爆开、碰撞等分层合成，按方向和遮挡播放 | 重建，不标为官方录音 |
| 3D 技能模型、运动、粒子、闪屏 | 参考官方演示后用 Three.js 绘制和模拟 | 重建；不是 Riot 原版网格、骨骼或粒子工程 |
| 场地、武器、界面 | 本程序自身绘制 | 简化训练环境 |

入口为 [Riot 官方特工列表](https://playvalorant.com/en-us/agents/)，素材文件下载自 `cmsassets.rgpub.io`。每张图、每段视频的精确下载 URL、字节数、SHA-256 及所属特工保存在 `public/assets/official/manifest.json`。音频的源视频、剪裁时间和 SHA-256 保存在同目录的 `audio-provenance.json`。

官方演示可能比当前补丁更旧，**只作为外观、动作和音色参考**，不能把视频里旧版本的引信、蓄力或满闪时长当作当前参数。原版图标和视频也不表示训练器的模拟已获得官方验证。

`scripts/sync-official-assets.mjs` 可重新从官方页面同步。`scripts/prepare-reference-audio.mjs` 需要 PATH 中有 FFmpeg / FFprobe；它检查实际音轨，跳过无音轨的官方演示。运行训练器不需要 FFmpeg 或联网。

公开页面未提供原始 3D 模型、动画文件和独立音效库，本次没有提取游戏客户端资源。素材仍属于 Riot Games；此仓库不是将这些素材重新授权给他人的素材包。
